# NovelMind MVP 功能目标

## 项目定位

NovelMind 是一个基于 RAG 的网络小说结构分析与写作辅助系统。

## 交付目标

完成一个本地单用户可运行的小说分析工作台。非模型功能在本地运行，
生成与理解类能力统一调用外部 API。

## MVP 功能规划

1. 上传 TXT 网络小说。
2. 自动按章节解析。
3. 保存小说和章节信息。
4. 展示章节列表。
5. 通过 DeepSeek API 生成章节摘要。
6. 后续加入角色抽取、RAG 问答和分析报告。

## 当前已完成范围

- FastAPI 后端最小入口。
- `/health` 健康检查接口。
- 基础目录结构和文档。
- TXT 小说上传与章节解析。
- SQLite 保存小说和章节。
- 资料库、分页章节元数据、按需正文读取和删除接口。
- DeepSeek V4 Pro 结构化章节摘要与持久化后台任务。
- 单章/全书生成、来源变化失效、幂等与并发保护。
- 外部正文处理披露、官方条款与隐私政策、外部处理和内容权利双重确认，
  以及强制覆盖二次确认。
- Streamlit 上传、资料库、正文阅读和摘要工作区。

章节摘要里程碑已经完成。下一阶段是角色抽取与统计；其模型推理继续使用
DeepSeek API。本地只负责确定性的数据处理与存储。
