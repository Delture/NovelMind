# NovelMind MVP 功能目标

## 项目定位

NovelMind 是一个基于 RAG 的网络小说结构分析与写作辅助系统。

## 交付目标

完成一个本地单用户可运行的小说分析工作台。非模型功能在本地运行，
生成与理解类能力统一调用外部 API。

## MVP 功能规划

1. 上传 TXT 网络小说。
2. 自动按章节解析。
3. 保存小说和章节信息。
4. 展示章节列表。
5. 通过 DeepSeek API 生成章节摘要。
6. 通过 DeepSeek API 完成人物抽取、人物归并和关系推理。
7. 使用硅基流动外部 embedding、本地精确向量检索和 DeepSeek 完成带引用的
   RAG 问答。
8. 通过 DeepSeek API 生成带章节依据的小说分析报告。

## 当前已完成范围

- FastAPI 后端最小入口。
- `/health` 健康检查接口。
- 基础目录结构和文档。
- TXT 小说上传与章节解析。
- SQLite 保存小说和章节。
- 资料库、分页章节元数据、按需正文读取和删除接口。
- DeepSeek V4 Pro 结构化章节摘要与持久化后台任务。
- 单章/全书生成、来源变化失效、幂等与并发保护。
- 外部正文处理披露、官方条款与隐私政策、外部处理和内容权利双重确认，
  以及强制覆盖二次确认。
- Streamlit 上传、资料库、正文阅读和摘要工作区。
- DeepSeek 人物安全分页抽取、跨批次全书人物归并和关系推理。
- 逐章来源缓存、失败时保留旧快照，以及本地人物提及与覆盖章节统计。
- 人物搜索排序、人物详情、出场记录、关系明细和 Streamlit 人物工作区。

## RAG 已完成范围

- 硅基流动 `Qwen/Qwen3-Embedding-4B`、固定 1024 维和官方 API 端点。
- 确定性分块、增量向量复用、版本化本地向量集合和 SQLite 原子索引指针。
- 索引范围/最大尝试数估算、外部处理与内容权利门禁、force 二次确认。
- 问题 embedding、本地检索、原文哈希复核和 DeepSeek 结构化回答。
- 引用白名单校验、证据不足标记、后台任务恢复、问答历史和纯文本展示。

## 分析报告已完成范围

- 只使用经过来源哈希复核的当前章节摘要，并可选使用当前人物快照。
- 长篇摘要通过 DeepSeek API 分批提炼、分层归并，再生成最终结构化报告。
- 执行摘要、情节、人物、节奏、主题、优点、风险和建议均携带章节依据。
- 引用章节必须属于当前小说；伪造、越界或重复引用会使任务失败。
- 报告输入哈希、模型和提示版本共同控制复用；刷新失败保留旧报告。
- 提供外部调用估算、数据范围披露、双授权、force 二次确认和纯文本界面。

章节摘要、人物分析、RAG 问答和分析报告里程碑均已完成。所有报告推理与
文本生成由 DeepSeek 外部 API 完成，本地只负责编排、校验和持久化。
