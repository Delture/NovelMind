# RAG 设计思路

当前阶段不实现完整 RAG，只记录未来设计方向。

## 目标

让系统可以基于小说原文回答问题，并辅助分析剧情、人物和章节结构。

## 初步流程

1. 将小说按章节解析。
2. 将章节内容切分成较小文本块。
3. 为文本块生成向量表示。
4. 将文本块和向量保存到 Chroma。
5. 用户提问时，从 Chroma 检索相关文本块。
6. 将检索结果和问题一起交给大模型生成回答。

## 后续需要考虑的问题

- 文本块切分大小。
- 中文网络小说章节标题识别。
- 人物名、地点名和事件信息的抽取。
- 向量库数据和 SQLite 章节数据之间的关联。
- RAG 回答中的引用来源展示。
