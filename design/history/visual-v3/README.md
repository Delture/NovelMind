## 视觉方向

- 借鉴 macOS 应用的固定侧栏、分段导航、分栏阅读和轻量工具栏。
- 暖纸白 `#FAF8F4`、燕麦侧栏 `#EEEAE2`、炭灰文字 `#302D29`、陶土强调色 `#A6593E`。主要操作使用深炭灰按钮。
- 无蓝紫主色、无渐变。边框和阴影保持克制，以留白区分信息层级。
- 1440 × 900 桌面设计；预览入口缩放展示，不代表移动端适配。
- 共享侧栏为可复用组件；界面使用 Noto Sans SC，阅读正文和主要标题使用 Noto Serif SC，品牌和统计数字使用 Inter。落地时可按操作系统使用系统字体栈。

## 第三版：Apple 设计语言

去掉全部仿系统窗口控制按钮。设计重点改为圆角层级、半透明材质、背景模糊、独立悬浮控件与克制的动效。

- 主侧栏与工具栏使用暖色半透明材质。
- 工作区导航脱离内容流，作为带模糊和柔和阴影的悬浮控制栏；内容保留净空，不被遮挡。
- 阅读页底部控制栏悬浮在阅读纸面上，圆角 18px；主内容圆角约 20–24px。
- 导航切换使用 View Transitions 的 130–260ms 淡出、淡入与轻位移；悬停/按压反馈 180ms，字号浮层 200ms。
- 浏览器预览的浮层支持 15–20px 正文字号调节、Escape 关闭和键盘操作；提交按钮随输入和三个独立确认项联动。
- 遵循 prefers-reduced-motion，关闭动画和位移。
- 侧栏、正文和分段导航保留 Claude 风格的暖纸色、陶土点缀与书卷气。

画布记录静态材质和布局。动态行为在 `prototype.css` 和 `prototype.js` 中实现。MCP 重新导出 HTML 后执行 `python design/enhance-preview.py`，可重新关联交互资源；此脚本可重复执行。

在本地 HTTP 预览中可体验完整切换过渡。直接打开文件时，受浏览器本地文件限制，跨页面操作可能回退到普通跳转。

第三版通过八页边界检查，以及当时的 10 项交互检查；结果在 `qa.json` 和 `interaction-qa.json`。仍未接入后端业务，未运行任何小说模型分析。

## 首次使用确认调整

已移除摘要、问答和报告中的重复确认区域。新用户首次打开会看到统一说明，可选择“同意并开始”或“仅使用本地阅读”；两种选择均会被记住，不在切换页面和刷新时重复询问。模型与密钥页增加“隐私与外部处理”入口，支持修改选择。选择本地阅读后，AI 操作保持禁用。

新增画布节点 `VmhZh` 为首次使用弹窗视觉稿。网页预览由原生 dialog 呈现，提供背景模糊和键盘焦点约束。

预览使用当前浏览器、当前来源的 localStorage 保存选择，不等于已实现软件后端的全局设置。实际接入时应将选择持久化到本机应用设置，并让请求保留服务端所需确认字段；本轮未修改业务后端。清除站点数据或更换浏览器会重新进入首次使用流程。

最新验证：八个页面无边界溢出；15 项交互检查通过，覆盖首次弹窗、刷新持久化、不重复询问、无常驻勾选框、设置撤回与重新开启。

## 正文目录：连续滚动

正文阅读已取消“第 1–50 章”范围选择及上一批/下一批。目录是固定高度、独立滚动的完整列表，当前章高亮，支持标题/序号搜索、无结果提示、定位当前章及键盘上下移动焦点。上一章/下一章直接按章节序号前进，首尾禁用相应按钮，不在 50 或 100 章处中断。

预览使用 128 章演示元数据（除已有章节名外，其余为示例标题），第 12 章保留原设计示例正文；其他章明确显示演示占位正文。该交互没有读取真实小说数据库。

正式实现时，接口可以分页取得元数据，前端将其合并为连续目录；超长小说使用虚拟列表或后台逐步加载。分页属于数据加载方式，不作为用户操作步骤。正文仍按选中章节请求。

`check-chapters.cjs` 已验证 128 条目录、独立滚动、50→51、100→101、首尾边界、标题搜索、空结果和当前章定位；结果保存到 `chapter-qa.json`。网页预览已检查。画布已更新对应图层，但本轮 pen.dev 的截图/边界计算对新目录仍出现渲染异常；静态导出和实际浏览器验证正常。
