# NovelMind：重新组织前端体验

这是一次信息架构与交互设计重构。原项目文档用来确认功能、数据和服务边界；原 Streamlit 页面布局不再是设计约束。

入口：`library.html`。通过页面内导航体验六个主界面，无需依赖外围的设计稿切换标签。

## 旧界面暴露了哪些不必要的操作

| 问题 | 新的流程 |
| --- | --- |
| 阅读目录每 50 章手动切批次 | 所有章节连续滚动、搜索、定位当前；正文按选章加载 |
| 书架、章节、分析导航同时占据阅读空间 | 阅读只有章节目录和纸面；通过“理解故事”进入书内分析 |
| 每页重复出现全局书架 | 打开书后侧栏只服务当前书，返回资料库再换书 |
| 摘要先选范围再选章节 | 连续摘要目录直接选择，待生成状态与已有结果同列呈现 |
| 生成设置、估算和任务长期占据结果区 | 点击操作才展示处理计划；所有任务集中在按需抽屉 |
| 创建任务后手动刷新 | 进度自动更新，切换页面不中断本次预览的任务 |
| 报告缺摘要时让用户自行跨页补齐 | “补齐摘要并更新报告”形成同一任务链 |
| 原文问答先理解索引管理 | 默认关注提问；尚未准备时提供“准备原文并提问” |
| 引用一直占一个侧栏 | 点击引用展开证据，需要时跳转正文并可返回原位置 |
| 导入和设置占独立页面 | 轻量弹窗，在当前上下文完成操作 |
| 权限确认反复出现在主页面 | 首次统一选择，后续在设置中修改 |

## 信息架构

资料库负责找书、导入和继续阅读。书内分为阅读、章节梳理、人物、原文问答、全书报告。任务、模型设置、权限、引用属于按需层，不与正文争夺常驻空间。

界面继续使用暖纸色和陶土强调色。半透明材质用于浮层、任务抽屉和阅读控制栏，正文保持足够实色与对比度。切换和展开采用轻量动画，支持减少动态效果。

## 验证与边界

`check.cjs` 已检查六页布局边界和浏览器脚本错误，并验证：

- 正文与摘要的 128 章连续目录、50→51、缺失摘要状态。
- 引用抽屉 → 原文 → 返回分析。
- 报告前置摘要任务串联、任务在页面切换后继续。
- TXT 文件选择、类型/大小限制、设置与隐私入口。

`qa.json` 记录结果。未调用真实生成/向量服务，未操作小说数据库。

这仍是可交互设计原型：任务使用本地计时器，刷新页面会重置演示任务；文件选择不会写入数据库；模型设置不会改动真实配置；第二、三本书仅展示资料库样式；示例人物与正文均为虚构内容。生产前端和后端尚未迁移。

后续落地需要保持后端任务持久化与确认字段校验，并增加任务链编排；不能把演示计时器或界面状态当作真实任务完成结果。对于万章小说，目录可采用虚拟列表，API 分页不应变成用户分页操作。

## 控件一致性精修

六个主界面的导入、返回、翻章、引用、发送等操作均使用独立矢量图标，保留人物关系正文中的方向箭头。按钮文字与图标统一用居中布局，动态改字时保留图标；仅图标按钮保留可访问名称。原文状态入口支持就绪和待准备两种紧凑状态。

搜索框增加统一搜索图标和聚焦反馈；弹窗关闭按钮改为标准图标；设置下拉选择使用统一自定义菜单，并支持键盘操作；折叠项使用可旋转图标；进度条、百分比、字号读数统一对齐。

最新 `check-controls.cjs` 覆盖六页控件几何中心、文字裁切、文本箭头扫描、下拉框键盘操作、折叠项、Escape 关闭与状态图标保留，结果在 `controls-qa.json`。`check.cjs` 的主流程回归亦通过。仅修改设计原型，未连接真实后端。

## 内容层次与间距优化

人物详情拆分为简介组与关系组，统计紧随简介；关系记录分别显示人物、关系类型、说明和章节依据，取消机器式箭头串联。摘要拆分为概览、事件、推进与操作组。报告拆分为标题信息、概览和阶段分栏。问答保留独立回答卡片，引用降为轻量链接；资料库收紧书封、信息与操作的留白。

浏览器的详情组采用正常文档流、Flex/Grid 和内容自适应高度，超长内容在面板内滚动；不再依赖固定纵坐标分隔段落。原文阅读的纸面与连续目录保持原有结构。

六页回归与控件检查通过。针对人物切换、短长内容、缺失摘要和分组间距另外检查：简介至统计间距 16px、引用入口高度 28px，三条事件无多余空行；长简介可以滚动且不覆盖关系区。pen.dev 静态源稿同步调整了分组与层级，运行时自适应行为由预览 CSS 实现。

## 阅读器前端设计

当前阅读页采用独立的 `reader.js`、`reader.css`，由 `app.js` 挂载。页面离开时会保存位置并清理监听器，其他功能页不受阅读主题影响。

已可体验：

- 全部章节连续目录、搜索、定位当前章；目录与书签双标签，侧栏可收起。
- 滚动阅读、章末继续下一章、首末章按钮状态与全书结束提示。
- 纸白、暖纸、夜间三种主题；宋体/黑体；字号、行距、正文宽度、段间距即时调整并记忆。
- 专注模式隐藏侧栏，空闲时弱化工具栏；鼠标移动恢复，Escape 退出。
- 进度面板按章跳转，本章滚动百分比显示；不把章节序号误称为实际字数进度。
- 书签新增、删除、跳转和空状态；阅读位置以章节、段落和字符偏移保存。
- 键盘翻章、Page Up/Down、F 专注、B 书签；输入框内不触发快捷键。
- 窄窗口使用可收起的覆盖式目录；支持减少动态效果。

本轮新增或更新 pen.dev 常规阅读、夜间专注与阅读设置画板。真实交互以浏览器预览验收；此前记录的原生画布截图限制仍适用。

阅读记录与偏好保存在当前浏览器来源的 `novelmind.reader.demo-v1`，属于前端原型存储。换浏览器、端口或清除站点数据会失去这些记录，未接入后端持久化或真实小说数据库。第 12 章扩充了自编演示正文，用于检验长文、书签与恢复位置；其他章节为演示内容。

`check-reader.cjs` 已检查主题/排版即时变化与存储、刷新恢复原段落、书签恢复跳转删除、目录显隐、专注与 Escape、50→51、首末章、Page Down、窄窗口无横向溢出、离开时清理主题。`reader-qa.json` 保存结果；主流程与控件回归也通过。

本轮未实现：真实章节加载与失败重试、跨设备同步、真实下一章预取、分页排版、划线批注、全文搜索。这些需要后续接口接入或独立迭代。

## 下拉菜单展开态修复

文本生成、文本向量和摘要并发统一使用页面内圆角菜单。触发器始终保持 12px 圆角，菜单 14px、选项 9px；选中态使用暖色背景和矢量勾选，避免系统原生方形蓝色下拉列表。原 select 隐藏保留为值载体；实际操作使用 combobox/listbox 语义并同步 input/change。

已验证鼠标选择、方向键、Home/End、Esc 仅收起菜单、Tab 收起、外部点击、单菜单展开和全部三个值同步。`check-selects.cjs` 与主流程回归通过，结果在 `select-qa.json`。
